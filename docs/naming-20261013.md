# Pet program names, repos and icon files (2026-10-13)

**Status: waiting for Astra to assign names.** Nothing below is created or renamed until she approves it.

## The rules (Astra, 2026-10-13)

- A **pet program** is the program (for example a shop of avatar gun effects). Its **pet program icon** is the character
  that represents it (Dubstep Gunsmith). The two names are always different (Astra, 2026-10-14).
- Every pet program has a **serial number** that never changes: `pet-program-1` is the Friendly Farmer's.
- **Placeholders show what still needs a name:**
  - no pet program name assigned yet → it is called `pet-program-#` (for example `pet-program-2`);
  - no pet program icon name decided yet → it is called `pet-program-#-icon-#`.
- **Every pet program has a repo, named after the pet program**, whatever its state (registered, pipeline, seed or roadmap).
  A pet program without a name gets the repo `pet-program-#` until it has one; GitHub keeps old links working after a rename.
- **Versions start with `v` and are on everything** (Astra, 2026-10-13): each pet program starts at **v1.0** and goes up
  as its changes are pushed (a git tag per version). A name keeps its number; a version never hides inside it.
- **Icon (mood) files:** `<pet-program>-v<version>-icon-<mood>-v<icon version>.png`, mood 1 to 9:
  1 calm · 2 blink · 3 happy · 4 curious · 5 worried · 6 sad · 7 sick · 8 shocked · 9 asleep.
  Examples: `the-farm-v1.0-icon-1-v1.0.png`, `dubstep-gunsmith-v1.0-icon-3-v1.0.png`, and while a program has no name,
  `pet-program-3-v1.0-icon-2-v1.0.png`.
- **Tool box labels:** `<pet-program>-v<version>-<tool>-v<tool version>`, e.g. `the-farm-v1.0-astras-pet-os-system-map-v1.0`,
  `pet-program-12-v1.0-repo-catcher-v1.0`. **Backlog:** the store `<pet-program>-backlog`, entries
  `<pet-program>-v<version>-backlog-<YYYYMMDD>-<NNN>`. Full rules: [PET-PROGRAM-FRAMEWORK.md](../PET-PROGRAM-FRAMEWORK.md), section 2.
- The astras-pet-os README lists every pet program with its **current version** under it, read live from its repo.
