**Provenance:** generated on Astra's OpenAI account (gpt-image-2, high quality, 1024×1024, one image each) through the
image bridge, with the shared pet STYLE from [scripts/generate-pets.mjs](../../scripts/generate-pets.mjs). The exact
per-seed prompts are in [scripts/generate-seeds-20261012.mjs](../../scripts/generate-seeds-20261012.mjs). Astra asked for
the art on 2026-10-12. Skill Scout is an original character in the Mommies' design (Astra's own characters): a sailor-style
outfit and long braids, with no copied elements from any existing character.

Pole Puff's approved art is on the branch `claude/pole-puff-draft-20261012` (`drafts/pole-puff/`).

The small icons in [art/icons/](../icons/) are made from these sheets (their calm top-left cell) and from the pipeline
pets' own repos by [scripts/make-icons-20261012.mjs](../../scripts/make-icons-20261012.mjs).
